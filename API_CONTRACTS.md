# API_CONTRACTS.md

Every HTTP endpoint that crosses a person-to-person boundary. Update your row
whenever your endpoint's request or response shape changes — don't let a
teammate discover a rename at integration time.

| Endpoint | Owner | Request | Response | Errors |
|---|---|---|---|---|
| `GET /api/weather` | Nishith | `?lat, lng, date` | `{ok, data:{maxTemp, precipProb}, meta}` | 400 missing param |
| `GET /api/trains` | Nishith | `?trainNumber, source, destination, journeyDate, classCode, quotaCode` | `{ok, data:{trainNumber, trainName, days:[{date, waitlistDepth, rawStatus, availableSeats?}]}, meta}` | 400 missing param, honest `ok:false` on RailRadar errors (ARP, invalid train, etc) |
| `GET /api/places` | Nishith | `?query, lat, lng, radiusMeters` | `{ok, data:[{placeId, name, lat, lng, rating}], meta}` | 400 missing param |
| `POST /api/routes` | Nishith | `{originLat, originLng, destLat, destLng, mode}` | `{ok, data:{distanceKm, durationMinutes}, meta}` | 400 missing param |
| `GET /api/fare` | Nishith | `?city, mode, distanceKm` | `{ok, data:{mode, distanceKm, fareINR}, meta}` — `meta` carries `estimate:true` | 400 only for missing `city`/`mode`/`distanceKm`. Unknown city/mode returns **200** with `{ok:false, error}` (`"No fare data for city: X"` / `"No fare data for mode: X in Y"`), same envelope pattern as the other provider routes |
| `GET /api/road` | Nishith | `?destId` | `{ok, data:{corridor, operators, frequencyPerDay}, meta}` — always `confidence:"low", estimate:true` | 400 missing destId, `ok:false` if destId not in seed |
| `GET /api/geocode` | Nishith | `?address` (required) | `{ok, data:{lat, lng, formattedAddress}, meta:{source:"geocode", confidence:"high"}}` | 400 `{ok:false, error:"address is required"}`. No match / upstream failure returns **200** with `{ok:false, error}`. Also called in-process by `services/travelTime.js` — the provider (`providers/geocode.provider.js`) is the shared unit, the route is a thin wrapper |
| `GET /api/v1/pressure/:destId` | Sathvik | `?date=YYYY-MM-DD` (required) | Full stored row: `{score (number\|null), components, dateVaryingSubtotal, staticSubtotal, dropped, degraded, lowConfidence, stale, destId, date, computedAt}` | 400 `{message:"date query param required (YYYY-MM-DD)"}` if `date` missing; 404 `{message:"unknown destId and no stored row"}`; 500 on internal error. Not the `{ok,data,meta}` envelope — raw row |
| `GET /api/v1/pressure/map` | Sathvik | `?date=YYYY-MM-DD` (required) | Array of the same row shape, one per tracked destination for that date (`[]` if none stored): `[{score, components, …, stale}]` | 400 `{message:"date query param required (YYYY-MM-DD)"}`; 500 on internal error. Registered before `/:destId` so `map` is never read as a destId |
| `POST /api/v1/budget/calculate` | Bharani | `{budgetINR, travellers, days}` required (numbers > 0); optional `tripId, destId, transport:{totalCost, source}, hotel:{pricePerNight, nights, rooms, source}, food:{pricePerPersonPerDay, source}, activities:[{pricePerPerson, source}], localTransport:{estimatedCost, source}` | **200** with the raw service result (no envelope): `{costBreakdown:{transport, hotel, food, activities, localTransport}` — each one `{amount, source}` — plus `totalCost`, `contingency`, `grandTotal`, `budgetINR`, `remaining`, `utilizationPercent`, `isOverBudget`, `reductionOptions`, `largestCategory` (string \| `null`), `tripId`, `destId`, `hasUnlabelledEstimates`. `contingency` is 10% of `totalCost` and is kept as its own line — **not** folded into `totalCost`; `grandTotal` = `totalCost` + `contingency`. `reductionOptions` is `[]` unless over budget, else four `{type, description}` entries (`reduce_hotel_cost`, `switch_to_train`, `remove_activity`, `lower_pressure_alternative`) | 400 `{error:true, message}` from `validateBudgetInput` — non-object body; `budgetINR`/`travellers`/`days` missing, non-number, or ≤ 0; `transport`/`hotel`/`food`/`localTransport` not an object; `activities` not an array; any negative/invalid `transport.totalCost`, `hotel.pricePerNight`/`nights`/`rooms`, `food.pricePerPersonPerDay`, `localTransport.estimatedCost`, or `activity at index N has negative or invalid pricePerPerson`. 500 `{error:true, message:"Internal server error while calculating budget"}`. Mongo persistence is best-effort and never fails the response |
| `POST /api/auth/signup` | Sathvik | `{fullName, email, password}` | 201 `{_id, fullName, email}`; sets `jwt` httpOnly cookie | 400 `{message}`: `"All fields are required"`, `"Password must be at least 6 characters"`, `"Email already exists"`. 500 `{message:"Internal Server Error"}` |
| `POST /api/auth/login` | Sathvik | `{email, password}` | 200 `{_id, fullName, email}`; sets `jwt` cookie | 400 `{message:"Invalid credentials"}` for both unknown email and wrong password. 500 `{message:"Internal Server Error"}` |
| `POST /api/auth/logout` | Sathvik | no body | 200 `{message:"Logged out successfully"}`; clears `jwt` cookie | 500 `{message:"Internal Server Error"}` |
| `GET /api/auth/check` | Sathvik | none — reads `jwt` cookie (`protectRoute`) | 200 with the **bare user document** minus `passwordHash` (not wrapped in `{user}`) | 401 `{message:"Unauthorized - No Token Provided"}` / `"Unauthorized - Invalid Token"`; 404 `{message:"User not found"}`; 500 `{message:"Internal server error"}` (note: an expired/malformed token throws in `jwt.verify` and surfaces as **500**, not 401) |
| `POST /api/alternatives` | Madhuri (route not yet built — Nishith wiring) | `{origin, destId, startDate, endDate, travellers, budgetINR, interests}` | `{requested:{destId,displayName,pressure,breakdown}, places:[...], dates:[...], relaxedRelief}` | TBD |
| `POST /api/visits/verify` | Pranay | `{businessId, code}` | `{visitId, tierAfter}` | 400, 409 |
| `POST /api/availability/:id` | Bharani | `{date, units, ...}` | `{ok: true}` | 400 |

## Naming contract
`destId` everywhere — always the canonical slug from Ananya's seed
(e.g. `"manali"`). Never a Google Place ID, never a display name.
