8. utils/ — Small reusable helpers

These should be generic, not business logic.

utils/
├── distance.js
├── date.js
├── response.js
├── validators.js
├── encryption.js
└── generateId.js

Example:

export function roundToTwo(value) {
  return Math.round(value * 100) / 100;
}

Don't put something like calculateTripCost() here.

That's business logic → services/.
